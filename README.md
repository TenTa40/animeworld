# iko (v10)

بازی موبایلی انیمه‌ای با Godot 4.3 — GL Compatibility. اسم بازی و قهرمان: **iko**.

## چی عوض شد (v10)
- مدل‌ها از کیت کامل Quaternius Stylized Nature MegaKit: درخت، کاج، درخت پیچ‌خورده، درخت خشک، بوته، چمن، گل، سرخس، قارچ، سنگ، سنگ‌ریزه.
- همه‌ی مدل‌ها برای موبایل کم‌پلی شدن (tools/lodgen.py): نسخه‌ی نزدیک (~۱۰۰۰-۱۷۰۰ مثلث درخت) و نسخه‌ی دور `_L` (~۳۰۰-۸۰۰)، نرمال‌مپ حذف، تکسچرها ۵۱۲/۱۰۲۴.
- دو لایه‌ی درخت و چمن با محو شدن نرم بین نسخه‌ی نزدیک و دور، بعدش ایمپاستور تا افق.
- شیدر چمن جدید: باد، له شدن زیر پای iko، بدون alpha-test.
- جاده‌ی خاکی (در صحرا شنی) با سنگ‌ریزه‌ی کنارش، شن موجدار، درخت‌های پاییزی نارنجی/زرد.
- رنگ‌ها پرانرژی‌تر و نزدیک به عکس مرجع.
- کنترل‌کننده‌ی خودکار فریم: اگه ۶ ثانیه زیر ۲۶ فریم بود، برد و تراکم و رزولوشن سه‌بعدی رو پله‌پله کم می‌کنه.
- رزولوشن سه‌بعدی روی گوشی: کم ۰.۶۷، متوسط ۰.۸، زیاد ۱.۰ (HUD شفاف می‌مونه).

## کاراکتر iko
- مدل کاربر (۲۹۷ هزار مثلث، بدون اسکلت) با `tools/herogen.py` به ۲۶ هزار مثلث با رنگ روی راس‌ها تبدیل شد: `assets/characters/iko.dat`.
- حرکت پا/دست/پارچه توی شیدر `hero_body.gdshader` ساخته می‌شه (اسکلت نداشت). اگه فایل خراب بود، بازی خودکار کاراکتر پروسیجرال قبلی رو می‌ذاره.
- فایل `.dat` با `include_filter` توی export_presets.cfg وارد APK می‌شه.

## تنظیم دستی
- `scripts/anime/nature.gd` → جدول `_make_cats` (تراکم `d`، شعاع `r`) و `TREE_R`.
- `scripts/anime/worldgen.gd` → `PATH_IN` / `PATH_OUT` (پهنای جاده)، `autumn` (پراکندگی درخت پاییزی).
- `settings.gd` → `auto_perf`.
- اگه رزولوشن سه‌بعدی مشکل داشت: توی `game.gd` تابع `_apply_settings` مقدار `sc` رو ۱.۰ کن.

## ساخت دوباره‌ی مدل‌ها
`python3 -I tools/lodgen.py <پوشه‌ی کیت (glTF و Textures)> assets/nature`

## تست‌نشده
محیط بیلد Godot نداشت؛ کد و شیدرها اجرا نشدن.
