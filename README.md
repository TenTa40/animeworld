# جزیره‌ی آرام — نسخه‌ی ۲ (انیمه‌ای)

نسخه‌ی جدید توی `scripts/anime/` و `shaders/anime/` هست. اگه به هر دلیلی لود نشه، `boot.gd` خودکار نسخه‌ی قبلی (`scripts/world.gd`) رو اجرا می‌کنه.

کنترل موبایل: جوی‌استیک چپ · کشیدن سمت راست برای دوربین · دکمه‌ها: حمله، پرش (توی هوا نگه‌دار = پرواز با گلایدر)، جاخالی، مهارت E، اولتی Q.
کنترل کامپیوتر: WASD · Space · J/F حمله · Shift جاخالی · E · Q · Esc مکث.
